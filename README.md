# Joshua & Asha — Christian Wedding Invitation Website

A luxury, cinematic, mobile-first Christian wedding invitation website crafted for **Joshua & Asha** with a device-adaptive video opening experience, authentic photography, and an emotional wedding soundtrack.

## 💍 Highlights

- **Cinematic Video Opening**:
  - **Laptops & Tablets**: Full-screen landscape wedding film (`video_landscape.mp4` / 1920x1080).
  - **Mobile Phones**: Edge-to-edge full-screen vertical wedding film (`video_portrait.mp4` / 1080x1920).
  - **Audio Control**: Tap anywhere or click "Tap For Song 🔊" to unmute and experience the film with audio.
- **Invitation Cover & Tap to Enter**: Luxury stationery card with double gold filigree and glowing entry button.
- **Wedding Soundtrack**: Emotional acoustic piano & strings arrangement of the timeless wedding chord progression (*Canon in D*).
- **Christian Faith Element**: Dedicated Holy Scripture section celebrating **Matthew 19:6** with illuminated radiant cross and floral accents.
- **Wedding Details**: Framed card with **Christian Wedding Service (5:30 PM)**, **Dinner & Reception (7:30 PM)**, and **Add to Google Calendar** integration.
- **Live Countdown**: Real-time countdown to **17th October 2026, 5:30 PM**.
- **Editorial Photo Gallery**: Authentic couple portrait of Joshua and Asha paired with supporting wedding macro photography.
- **Interactive RSVP**: Attendance confirmation, guest count selector, prayer/blessing message, and celebratory confetti burst.
- **Minimal Navigation**: Bottom navigation bar with floating audio toggle.

## 🛠 Tech Stack

- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS + Custom Gold Foil & Sheen Keyframes
- **Motion**: Framer Motion
- **Icons**: Lucide React
- **Celebration**: Canvas Confetti
- **Audio**: Web Audio API Procedural Wedding Arrangement

## 🚀 Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
